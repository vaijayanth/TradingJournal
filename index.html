Unlock Advanced Analytics — Add These Columns to Your Sheet
Inspired by real trader analysis: MAE + MFE:MAE ratio separated 14% win rate from 100% across 24 consecutive wins
🔑 MAE % — Most Powerful Signal
Max Adverse Excursion — how far the trade went against you before recovering or stopping out.

Real data: MAE <1.5% → 100% WR · MAE >3% → 21% WR

Add col O: Formula =MIN(low range during trade) → compute =(entry-min)/entry*100
Add column O → maeCol in Config
🔑 MFE % — The Game Filter
Max Favorable Excursion — highest point reached while in the trade.

Real data: MFE:MAE >3x → 100% WR on 24 consecutive trades · <3x → 14% WR

Add col P: Formula =(max-entry)/entry*100 during trade
Add column P → mfeCol in Config
⏰ Entry Time
What time did you enter? Real analysis showed 09:00–11:00 IST (GTT) = 0% WR · 15:00–15:30 IST = 78% WR

Add col Q: Entry time as text e.g. 09:15 or 15:00
Add column Q → entryTimeCol in Config
🏷 Trade Quality Tag
Tag each trade honestly at exit:
Rule ✓ / Emotional / Moved Stop / Late Entry / Oversized

This is the single most powerful improvement tool.
Add column T → qualityTagCol in Config
🏭 Sector
IT / BFSI / Pharma / Auto / FMCG etc.

Reveals hidden concentration — when market rotates, correlated positions all hit stop simultaneously.
Add column N → sectorCol in Config
📝 Exit Reason
Stop / Target / Rule-based / Time

17 of 18 losing trades in the example had correct entries — the leak was in exit management. This column proves it.
Add column G → exitReasonCol in Config
